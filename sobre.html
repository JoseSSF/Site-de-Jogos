Sobre mim

Olá! Meu nome é José Soares e sou estudante de Engenharia de Software na Unicesumar, atualmente no 4º semestre. Sou apaixonado por jogos e sempre tive curiosidade em entender como eles são criados, o que me levou a estudar mais sobre programação e desenvolvimento de software. Meu grande objetivo é me tornar um desenvolvedor de jogos, unindo minhas duas paixões: tecnologia e games.

Este blog foi desenvolvido como parte de um projeto acadêmico para a disciplina de Programação Front-End. Ele tem como objetivo apresentar recomendações de jogos que eu gosto, com links diretos para suas páginas na Steam ou sites oficiais.



Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript

Destaques do projeto

  • Design responsivo, adaptando o layout para diferentes tamanhos de tela.
  • Organização dos jogos com links diretos para mais informações.

Próximas melhorias

  • Adicionar novos jogos com descrições mais detalhadas.
  • Incluir vídeos de gameplay para uma experiência mais completa.
  • Explorar recursos interativos, como uma área para comentários e avaliações dos visitantes.
